# Design lessons

What this project's owner has taught the ultrahand skills. Every skill reads this before
it starts. Format: ultrahand `shared/learning/README.md`.

## L1 · grouping · 2026-11-03
- **Rule:** Put a group's label (a task's ref and title) above its members, and indent the members under it; never name the group after its members.
- **Why:** With the task caption below its files, the owner couldn't tell which task the files belonged to ("Are these 3 part of T231?").
- **Applies to:** all
- **From:** the owner's correction on the goal page's Attached concepts (concept A)

## L2 · navigation · 2026-11-03
- **Rule:** Don't use tabs or a segmented control to switch between waves, or any set that grows with the goal; use a pop-up menu instead.
- **Why:** Goals can have many waves, so the tabs get very long.
- **Applies to:** desktop, mobile, tablet, review
- **From:** the owner's correction on the goal page's Attached concepts (concept B)

## L3 · lists · 2026-11-09
- **Rule:** Cap every list that grows with the data: show the first few rows and a count of the rest. A "Show more" adds a fixed number of rows, then counts what's left; rows inside a group show only when the group is opened.
- **Why:** The goal card's task list and the Shipped list's "Show more" had no limit and grew too big.
- **Applies to:** all
- **From:** the owner's notes on the recap component catalog (goal card, Shipped)

## L4 · charts · 2026-11-09
- **Rule:** Don't add an "As a table" disclosure under a chart; label the values on the marks instead.
- **Why:** The values were already on the marks, so the table repeated the chart.
- **Applies to:** all
- **From:** the owner's notes on the recap component catalog (seven charts)

## L5 · colour · 2026-11-09
- **Rule:** Don't leave cards and group rows bland: give a goal or project its project colour (a tinted card, a coloured swatch and bar on its row), and show good versus bad with colour plus a shape, with the thresholds written in the rule.
- **Why:** The owner called the goal card and the Shipped list bland, and asked for plan quality to show good versus bad at a glance.
- **Applies to:** all
- **From:** the owner's notes on the recap component catalog (goal card, Shipped, plan quality)
